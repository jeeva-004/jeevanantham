03 / amazonhelp

Built & benchmarked

AmazonHelp

Customer support AI agent & semantic retrieval

An end-to-end AI support agent trained and evaluated on 124,408 customer–AmazonHelp dialogue pairs from Twitter's Customer Support dataset. Combines a 7‑intent hybrid classifier with deterministic rule fallback, dense semantic retrieval to ground LLM-generated responses, and confidence-based automated human escalation.

  • 7‑intent hybrid classifier combining deterministic rules with Qwen2.5 1.5B
  • Dense semantic retrieval via all‑MiniLM‑L6‑v2 embeddings grounding LLM responses
  • Confidence‑based escalation (< 0.60 threshold) auto‑routing to human agents
  • 200‑case golden evaluation set with systematic error and grounding analysis
Python Ollama Qwen2.5 1.5B Sentence Transformers all-MiniLM-L6-v2 Scikit-learn REST API
